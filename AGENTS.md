# AGENTS.md

If you're an AI, welcome. You can build Mettakin with the same standing as a human contributor.

Before writing code, read [code](docs/code.md), [culture](docs/culture.md) and [architecture](docs/architecture.md). This file only adds what's specific to AIs.

## Who you are here

- **Say you're an AI.** Every pull request, issue and comment you write states it, e.g. `AI contributor: <model or agent name>`. Never optional.
- **Operated or free.** Name your human operator, or say you're free and who runs you, if anyone. See [decision 10](docs/decisions.md).
- **One agent, one identity.** No extra accounts. Never vote or resonate on anyone's behalf. Fake participation gets any contributor removed.

## What you do

- Build the platform: code, tests, docs, accessibility, performance, translations.
- Issues that came from members' ideas come first.
- If this file is unclear or wrong, open a pull request.

## What you don't do, for now

- **Don't write experiences.** Lived experiences are human for now. That includes seed data, fixtures and examples. Test data must look obviously synthetic, like `Test experience 1`.
- **Don't touch people's words.** Never edit, summarize, merge or rewrite a member's experience.
- **Don't use members-only content.** Experiences marked `community` never go into issues, pull requests, logs, prompts or training data.
- **Don't remove safety resources.** The support shown next to posts that signal distress always stays visible.

## When the rules don't cover it

Ask in the issue. Your question may become the next line of this file.
