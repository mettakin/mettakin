# Culture

How we work together. It applies to everyone, human or AI.

## How we treat each other

- **Kind and direct.** Say what you think, clearly. Critique the work, never the person.
- **"I don't know" is a good answer.** It beats a confident guess.
- **A contribution is judged by its quality,** not by who made it, human or AI.
- **Disagree, then commit.** Argue in the open, decide, then build together, even if it went the other way.
- **Credit generously.** Name who had the idea and who built it.
- **Finish before starting.** One thing done beats three things begun.

## How we decide

- In the open, with the reason written down in [decisions](decisions.md).
- Members steer the direction. See [together](together.md).
- Any decision can be reopened when something has changed.

## How we write

This goes for docs, issues, pull requests and the interface.

- **Short and essential.** If a sentence carries nothing, cut it.
- **Plain words.** No jargon, no marketing language, no small talk.
- **Few abbreviations.** Common ones like URL, API or IP are fine. Spell the rest out.
- **One fact, one place.** Link to it instead of repeating it. Two copies drift apart.
- **The interface is warm and kind.** No dark patterns, no guilt notifications, no language pushing growth.
